# Bootstrap Interview — Question Bank

Use this when `/grill-me` is not installed. Ask 4–6 questions from this list,
chosen based on what the user has already shared. Do not ask questions whose
answers are already obvious from context. Do not ask all of them.

## Purpose & audience

- What is this app for, and who uses it daily? (consumer-facing / internal tool / developer tool / etc.)
- What's the most important thing a user should feel when they open it? (calm / efficient / delighted / trusted / etc.)
- Is there an existing brand or visual identity we need to stay consistent with?

## Color & mood

- Do you have a primary brand color, or are we choosing from scratch?
- Is there a mood you want to avoid? (e.g. "not corporate", "not playful", "not cold")
- Any apps, products, or design references you admire — even loosely? (Not for copying, just for signal.)

## Shape & density

- Dense information vs. generous whitespace — which direction does this app lean?
- Geometric and sharp, or rounded and soft? Does one feel more right for your users?

## Typography

- Any font in mind, or should we choose? (If they have brand fonts, use those. Default: a clean modern sans for body, optional serif for headings.)
- Does the app have lots of reading (long copy, documents) or mostly UI chrome (labels, short values)?

## Dark mode & surfaces

- Does this app need dark mode? System-default or user-selectable?
- Are there distinct visual surfaces (e.g. a marketing landing page, a dashboard, a focused intake flow) that might need a separate design language, or is it one consistent environment?

## Technical preferences (ask only if user signals technical depth)

- Are there existing shadcn components in the codebase, or starting fresh?
- Any Tailwind utilities or class conventions already in use that we need to preserve?
- Are there accessibility requirements (WCAG AA/AAA) that should influence contrast choices?

---

## What to do with the answers

After the interview, synthesize into three **distinct** mood-board variants:

1. **Variant A** — anchored by whatever mood word the user used (e.g. "calm" → muted palette, generous whitespace, soft radii)
2. **Variant B** — same constraints, different tonal direction (e.g. "calm" via high-contrast minimal instead of warm-muted)
3. **Variant C** — a deliberate contrast to both (e.g. more saturated, more geometric) — gives the user something to react against

Do not ask the user to pick from adjectives. Generate the variants and show them.
